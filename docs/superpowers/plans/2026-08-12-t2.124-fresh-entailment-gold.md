## 2. The justification, written to cite no result

This text (or its close paraphrase) is what the round's ledger entry and the LABELLING.md
round section record as the grounds. Neither ground references how any judge scored, and
the review of this plan should attack exactly that property:

1. **Publication contamination.** The retired gold's false-positive censuses, duplicate
   findings and per-slice miss decompositions are published in `gate-ledger.md`, in the
   dated eval reports, and in the resolution brief. A pair set whose failure surface is on
   the public record cannot measure any future judge without the measurement being
   attributable to authorship-with-answers, **independently of what any run scored**.
2. **The entailed class was never lattice-sized to its own bar.** T2.118: no T2.110-style
   sizing was ever run for the entailed census; 0.90 is not expressible on it (pooled
   entailed enforces 0.9017 by quantisation), and the class carries five duplicated
   propositions across seven findings with one three-row component. These are properties
   of the census's arithmetic and composition, not of any judge's output.

The discipline that keeps this honest: nothing else may enter the grounds. In particular,
"the judge missed value-swap" or any slice-level performance fact is **barred from every
artifact this round produces** — the frame, the briefs, the round section, the ledger
entry, the commit messages.

## 3. Decisions the plan derives from code and protocol (forced moves, with the evidence)

These are stated up front because each one, got wrong, fails the round quietly.

**D1 — The fresh gold is a wholly new file at the canonical path; the old file is
archived, not retired-in-place.** `refuse_retired_pair_set`
(`run_judge_qualification.py:158-196`) calls `entailment_gold.retired_pair_overlap` over

the new file at that exact path.

**D2 — Ids continue the series at `eg-0418`.** `RULE_B_FIRST_ID = "eg-0242"` filters
`id >= …` open-ended upward and **the constant does not move** (owner ruling R3;
T2.115's branch-review correction M-1). Starting the fresh gold at `eg-0418`: (a) every
fresh pair is in Rule B's population, so **pooled and Rule B coincide** — the honest

no disclosure that Rule B vanished) — that is the trap this decision closes.

**D3 — Fresh premises; the existing harvest is exhausted and its rows are excluded.**
Measured on the committed files: `l2_harvest.json` holds **62** facts, all 62 are used by
the retired gold, at the ≤ 4-pairs-per-premise cap (max observed = 4). A fresh l2-fact
census on the old manifest is impossible without re-using retired premises — and for
slices whose hypothesis the premise **determines** (`direction`: the hypothesis *is* the
reversal), re-use reproduces retired content byte-for-byte, which the runner refuses, or
near-verbatim, which reproduces propositions whose verdicts are on the public record. So:
grow the bench corpus, re-harvest, and **exclude the 62 old `triple_key`s from the
assignment** (the exclusion list is mechanical data — keys, not content).

**D4 — Class censuses land on their bars' lattices, and both readings coincide by
construction.**
- Contradicted census **C = 80**: 0.95 sits on a recall lattice only at `n ≡ 0 (mod 20)`;
  80 is T2.110's ratified size (76/80 = 0.9500 exactly), fits the Layer-3 resample's
  full-census first stratum inside the ratified n = 93, and re-adopting a ratified size is
  a precedent citation, not a fit.
- Entailed census **E ≡ 0 (mod 10)** so `groundedness_gate_recall_bar` = 0.90 is exact
  (the worked frame below lands on E = 140, 126/140 = 0.9000). This is the sizing the

- Unsupported census is no barred metric's denominator (T2.118) and is unconstrained.
- Precision bars (entailed 0.95, contradiction 0.70) have judge-dependent denominators
  and **cannot** be sized; the frame says so rather than pretending otherwise.
- **Zero within-class duplicate propositions is an authoring gate** (§7 step 9). With
  zero duplicates, rows = independent propositions for every class, both readings of the
  disclosure coincide, and T2.118's exact-minimum robustness hazard (a rows-pass whose
  independent reading fails) is unrepresentable rather than merely disclosed.

**D5 — The frame is committed code with zero free parameters, before any pair exists.**

## 9. Residuals and done-when honesty — what is *not* achievable as written

- **U1 — "The authoring party is not the adjudicating party" is structural, not
  epistemic.** Authors and both blind labellers are Claude-family agents; the recorded
  history is that pass B "added ~zero bits and diverged identically to pass A". The
  structure (separate dispatches, no shared context, stripped export) is the achievable
  property; genuine label independence enters only at the Layer-3 resample, on one
  non-Claude model. Record that residual in the round report — claiming more would repeat
  the defect the Steps 0–5 review found.
- **U2 — "Neither references which slices any judge has missed" is achievable as a
  property of the artifacts, not of the people.** The miss decompositions are published
  in this repo; the controller and the frame-script author have read them (this plan's
  author has). The achievable and verifiable form is: zero degrees of freedom exercised
  in the frame (D5), plus an independent review attacking exactly that (step 6) — the
  same shape as the 2026-08-10 delegated adjudications. A reader who wants to discount
  the round knows exactly what to discount.
- **U3 — Freshness is content-level, not proposition-shape-level.** The closed
  16-relation taxonomy and the bench-corpus domain mean fresh pairs will resemble retired
  ones in *shape* (there are only so many ways to swap a host). Only byte-identity is
  refused by machinery; §7 step 9's near-screen narrows the gap; the residual is
  disclosed, not closed.
- **U4 — The entailed lattice sizing fixes recall's denominator only.**
  `entailed_precision` (0.95) and `contradiction_precision` (0.70) have judge-dependent
  denominators; no census makes them exact. The frame states this so nobody later reads
  "sized so their bars are expressible" as covering four bars when it can cover two.
- Everything else in the done-when is achievable as written, and one clause is **already
  done**: the `4975c5cc` retirement + every-role refusal landed with T2.117 (D6);
  this round verifies and cites rather than re-implements.
