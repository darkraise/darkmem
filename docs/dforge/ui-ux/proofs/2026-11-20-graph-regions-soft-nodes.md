## Delta

**UI/UX depth:** touch — owner request 2026-11-20 on the memory graph: "enhance the cluster region drawing, reduce the redundant and unnecessary lines and curves", "hide the cluster label over the cluster (the one that always show) when cluster region showed up", "The node now is tearing too much, not soft and smooth as before."

- **UI-1** — With Regions on, each cluster's region is its members' convex hull grown by 22 screen pixels: straight edges joined by a circular arc round each corner, so the outline is convex and smooth, with no tail, kink, overshoot or loop at closely spaced corners. Two members draw a capsule. The outline is a solid 1 px stroke at 0.3 opacity over a 0.07 fill; the dashed stroke is gone.
- **UI-2** — With Regions on, the cluster names at each island's centre are not drawn. Each region is named once, by its chip ("name · count", names over 40 characters end in an ellipsis, "Cluster N" when no name was derived), at every zoom (the chip used to show only when zoomed in).
- **UI-3** — A chip sits just inside the top of its own region, centred on the outline's top point, never in the gap above it. Larger regions place first; a chip that hits a placed chip moves below it; chips never overlap. A chip is pulled inside the canvas edges and below the 48 px toolbar band, and is dropped when its region is off screen (above, left or right) or when no free position remains.
- **UX-1** — Turning Regions off brings the centre names back; a selection makes the chips recede to 35% opacity, as the centre names do.
- **UI-4** — Memory nodes draw with a soft edge: the disc fades over 30% of its radius (at least one screen pixel), centred on the radius, where it used to fade over half a pixel. No memory disc is drawn narrower than 2 screen pixels in radius, where the lightest memories used to shrink to about 1 px specks at the fit view. The hover and selection rings follow the same 2 px floor. The code graph's nodes are unchanged.
- **OP-1** — Proven on the live page with the cloned corpus at 1280x800 and 1920x1080, light and dark, with 0 console or page errors and 0 attempted writes.

## Decisions

Rulings that are mine, reported for review:

- **Chips name the regions, not the centre names.** The owner asked to hide the always-on names. A chip used to show only when zoomed in, which would have left a fit view with Regions on unnamed, so chips now draw at every zoom and carry the placement rules the centre names had (edge clamp, toolbar band, no overlap).
- **Chips sit inside the region's top.** Packed regions touch, and a chip hung above its outline landed in a neighbour's fill, reading as the neighbour's name (first live build: "File Replace Retry Issues" over the DST region).
- **The node softening is limited to the memory canvas** (`SOFT_DISC` define). The code graph uses the same glow program with the same half-pixel edge; changing it was outside the request.
- **The minimum disc is 2 px.** It removes the grain at the fit view while leaving the crisp cap (30% of node spacing) in charge of every larger disc, so neighbouring points stay separate.
