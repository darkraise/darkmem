A repository that has never been indexed has no graph to show — this is not a filtered-to-nothing result, and the empty state names the exact action that resolves it (the reindex dialog lives on the Repositories tab, S14; this screen only points at it, it never opens it inline).

Code Graph — error (clone/index failure)

Honesty rule: error ≠ empty list. A clone or index failure surfaces the message the repo.*_failed event carries (doc 10 §4, doc 13 §4.2) rather than rendering the same bare "no graph" copy as a never-indexed repo — the two failure causes must never look identical, or a user fixing the wrong problem never resolves either one.
