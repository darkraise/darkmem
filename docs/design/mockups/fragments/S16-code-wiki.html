Overview

backend/app is a FastAPI service organised into api/routes (REST), api/mcp (the FastMCP tool family mounted at /mcp), services (the ingestion pipeline and its supporting orchestration), repositories (graph, relational, and vector data access), and models/schemas. The process entry point is app/main.py, which also registers the seven periodic jobs under JobRegistry.

Ingestion pipeline

ProcessingPipeline.process_batch is the central write path. It moves a batch of memories through five phases — content embed, extract-and-classify, entity embed with cache, dedup, and write — committing the vector and graph halves of phase five in separate savepoints so a graph failure never rolls back the vector write.

  • services/pipeline.py — phase orchestration, savepoint boundaries
  • services/extraction_clean.py — entity/relationship extraction
  • services/code_pipeline.py — this repository's own indexing path

Code · Wiki — empty (points at the reindex dialog)

Honesty rule: never implicitly generate on browse (doc 10 §8). GET /code/wiki reads or returns empty — it never spends LLM budget just because a page was opened. So the empty state does not say "check back later"; it names the exact control (generate_wiki) and shows the dialog it lives in, because a wiki only ever appears here as the side effect of a reindex a human opted into.
