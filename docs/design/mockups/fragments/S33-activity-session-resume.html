S33 — Activity · Session checkpoints & resume

The Activity-shell surface for the server-side checkpoint store (spec 2026-07-25 §Feature-2): a run's progress is captured as a compact digest keyed on its origin_key (the agent-run identity, doc 05 §2.1) into session_checkpoints, and resume is a specialised inject — at session start the latest digest is written into the tool's CLAUDE.md managed block under the inject token budget (doc 15 §3.2), so a fresh session loads a small digest instead of reloading a full context window. Checkpoints are operational digests, not vault knowledge: they carry no verification badge, and every save/resume is journaled to events (doc 04 §8.1).

A checkpoint is operational, not knowledge (invariant 23). It renders a session digest · not verified knowledge label, never a verification badge — a checkpoint is a run's working state, not a corroborated fact, and dressing it in the vault's badge vocabulary would over-claim. Checkpoints never enter the Facts / Articles vault, and the resume inject that carries them is a delivery of stored state, not a second ranking path (invariant 17).

Resume — the digest written into CLAUDE.md at session start

Shown in one theme. Resume is a specialised inject (doc 15 §3.2): the client fetches checkpoint_latest for (project, origin_key) and rewrites a marker-bounded managed block in CLAUDE.md, strip-before-rewrite so a re-resume never duplicates. The block is small on purpose — this is the whole point of the feature: the new session reads ~1,850 tokens of digest instead of reloading a full context window whose prompt cache has expired.

The block is the darkmem region and nothing else. The writer may read the whole file but only replaces the bytes between the two sentinel comments, so a human's own CLAUDE.md rules above or below survive every refresh (the same strip-before-rewrite discipline that makes re-extraction idempotent). Every write journals a resumed event, so the run timeline in the hero board above shows exactly when a fresh session picked the digest up.
