S24 — Activity: calendar day drill-down

/activity/day/$date — a calendar-day click drills into that UTC day-bucket's slice of the durable events substrate (doc 13 §6.4, doc 04 §8.1). This is the same event-row component the per-object timeline renders (doc 14 §6, realised for one memory in S05): timestamp, an event-type chip (neutral role, drawn from the closed event_type vocabulary), an object link, and — only for verification transitions — the from→to rung pair as two small .badge pills joined by an arrow. Every module composes the shared vocabulary: .badge rungs from mockup.css, and C04's surface/skeleton/alert/empty classes for the non-populated states. populated renders as the hero in both themes; loading, error, and empty render once each in the default theme, since the shared toggle guarantees theme parity.

Activity day drill-down — error

Honesty rule: error ≠ empty list. A failed day-bucket read raises a named error rather than rendering an empty timeline indistinguishable from a genuine quiet day (doc 07 §2, invariant 14) — retry stays offered, and the calendar link back stays available.

Activity day drill-down — empty

Honesty rule: empty says WHY. No activity on this day is an honest, ordinary outcome — the empty state names the UTC bucket it checked rather than rendering a bare blank (doc 14 §5).
