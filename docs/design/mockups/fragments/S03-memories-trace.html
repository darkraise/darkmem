Score bars: chart-token identity, never the caution token. Every bar above resolves from only the four non-caution chart members — --chart-1 semantic, --chart-2 keyword, --chart-3 ppr (and its dual_level sibling at a lightness-shifted variant of the same token), --chart-5 rerank (and the rank_fusion_factor sub-arms at further lightness-shifted variants of that token) — --chart-4 is never used for an arm, so a bar can never be misread as a caution signal (doc 14 §4). Colour never carries the value alone: a number is printed beside every bar.
Dormant arms render dormant, never omitted, never zero. ppr is muted and labelled "inactive · ppr_enabled=false" on every row above — the channel did not run this request — and the same treatment applies to the importance/heat/ recency rank_fusion_factor sub-arms, whose weights are 0 in the envelope's weights snapshot. Omitting the bar would hide that the arm exists; drawing it at a literal zero would wrongly imply it ran and found nothing — this is invariant 23 read into the trace: built-but-unspent signals look built-but-unspent.
Grouping indents, never repeats as a sibling. The memory that supports the Facts-section fact nests directly under it with a dashed connector and its own full label cluster + score breakdown — it is still a fully-explained row, just visually subordinate to the fact it grounds (doc 14 §4).
