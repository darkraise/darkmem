C04 — Render-state skeleton

The reusable state pattern every screen instantiates on top of one .c04-surface shape: empty · loading · error · populated, plus the staged, degraded, and empty-with-exclusions variants (doc 13 §4, doc 14 §5). Each header chip below is one of the seven .state-chip variants already declared in mockup.css — this fragment is where they are first put on screen, composed rather than re-invented. populated renders as the hero in both themes; the other six render once, in the default theme, since the shared theme toggle guarantees parity.

Render state — empty

Honesty rule: empty says WHY. An empty result never renders as a bare blank — the copy states the cause and what happens next (doc 14 §5). The vault's cold-start register is reproduced verbatim below (doc 13 §5.1); the row underneath shows the other two registers doc 14 §5 names — no-match and healthy-empty — because one generic "nothing here" string cannot honestly cover all three.

Render state — loading

Loading is a layout preview, not a spinner replacing the page (doc 14 §5): skeleton rows mirror the exact chip / badge / text / meta slots the populated board below fills in, so the surface never jumps once data resolves.

Render state — error

Honesty rule: error ≠ empty list. A both-sided channel failure raises a named error rather than returning zero rows indistinguishable from a genuine no-match (doc 07 §2, invariant 14) — retry stays offered and last-known cached data renders where cached, never silently swapped for an empty state. Honesty rule: partial names its failed step. A pipeline partial status never says just "something failed" — it names the failed phase (embed / extract / vector / graph, Phase 1–5) so the caller knows exactly what is missing.

pipeline: partial — failed step: extract (embed ok · vector ok · graph incomplete) 3 of 5 memories affected

Render state — staged

Honesty rule: staged ≠ empty panel. A surface whose backend signal has not shipped renders a labelled placeholder naming what will appear and what it is waiting on — never a fake-populated mock, never a blank that looks broken (doc 14 §5, invariant 23).

Render state — degraded (populated-with-caution)

Honesty rule: degraded ≠ fewer rows. A one-sided channel failure degrades gracefully — the surviving channel's full row count still renders, flagged by a persistent caution banner, never a silently shorter list (doc 14 §3.6, doc 07 §2). Verbatim banner copy below.

Render state — empty-with-exclusions

Honesty rule: empty-with-exclusions ≠ bare empty. When scope or context excludes every candidate row, the exclusion strip renders before the empty body, so the surface reads "0 shown, N excluded" rather than "nothing found" (doc 14 §3.6/§5).
