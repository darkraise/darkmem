Memory detail — deprecated

Also retained, not hidden. deprecated is the demoted end of the same lifecycle: when a memory that others point at via superseded_by is itself deleted (here, the TTL sweep in expired_memory_cleanup), its dependents are demoted to deprecated with superseded_by cleared to NULL first — the FK is ON DELETE SET NULL, so skipping that demotion would violate chk_superseded_has_pointer. That is why this board shows the amber .badge.deprecated with no successor link, unlike the superseded board above.
