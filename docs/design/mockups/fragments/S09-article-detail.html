Partition boundary

Because pgvector requires a fixed-dimension vector(N) column, darkmem partitions embeddings by embedder fingerprint instead of storing every model's vectors in one table.F1 Each fingerprint gets its own four child tables — memory_embeddings__<slug>, entity_embeddings__<slug>, code_chunk_embeddings__<slug>, and entity_embedding_cache__<slug>.F2

Registration & safety

The embedders table is the fingerprint registry, and embedder_registry.register creates all four child tables idempotently with CREATE TABLE IF NOT EXISTS.F3 Application code never names a partition directly; it always resolves the table name through child_table(parent, fingerprint).F4 _register_fingerprint must run before any insert into a partition — the ingest pipeline registers the content fingerprint in its embed phase, and re-registers mid-batch if the active embedder rotates.F5 A query that joins across two different fingerprints has no defined cosine distance, because vectors from different embedders are not comparable — cross-fingerprint joins are treated as a bug, not an edge case.F6
