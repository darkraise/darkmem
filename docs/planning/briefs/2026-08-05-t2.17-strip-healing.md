## What would make this task worth its own row

A test that passes because the property is *unreachable* rather than *held* proves nothing —
that exact shape was found twice in T2.16 and cost a fix round. So for each clause, show the
negative is non-vacuous: mutate the mechanism and watch your test go red, and say so in the
report. Specifically:

- **Idempotence:** two identical runs leave byte-identical blocks and the second writes no
  journal row — *and* a changed corpus produces a different set, so the test is not just
  observing a no-op.
- **Self-healing:** deleting an endpoint removes the edge — *and* the edge genuinely existed
  first, with the deletion being the thing that removed it rather than a strip that would
  have run anyway.

**If you find the property does not hold, report it rather than adjusting the test.** That
is the finding; T2.16 is `done` and a real defect here reopens it, which is legitimate.
