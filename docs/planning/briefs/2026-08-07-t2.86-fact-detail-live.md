## The one clause that is certainly outstanding

Added 2026-08-07 from T2.48's rescope:

> **A stale code citation renders as stale.** T2.48 serves `FactSourceGroup.stale` and
> types it on the frontend, and `fact-sources.tsx` reads it **nowhere** — so a human
> auditing a downgraded badge sees the broken citation looking identical to a live one.

That is the visible-cause story ending at the API boundary, and it matters because the
whole point of T2.48's design is that a stale citation **downgrades a badge rather than
expiring the fact** — the human is supposed to decide. A human who cannot see which
citation broke cannot make that decision.

Doc 10 §6 is explicit that a stale citation is "a badge signal on the fact (doc 08's
downgraded/under-review surface — a demotion of corroboration, not `disputed`, which is
reserved for a contradiction; rendered by doc 13)". So the rendering is specified; what
it must not do is imply a contradiction.
