## What was measured (2026-08-12, reproduce it before changing anything)

`backend/scripts/benchlib/entailment/verdicts/` holds **80 files; 79 are synthetic
residue.** Seven of those carry the real gold's exact shape (173 entailed / 80
contradicted), the real deepseek identity `4d886440`, and real gold shas including the
current `6eadba73` — one is named `2026-08-12-4d886440-6eadba73.json`, which is precisely
how a genuine deepseek run on today's gold would be named. Their metrics are garbage:
entailed precision 0.3731 against deepseek's published 0.9938. Mtimes span 08-10 (25),
08-11 (20) and 08-12 (36), so the leak is **active**, not one historical accident.

Only `2026-08-12-fd39e7b2-6eadba73.json` is genuine — it reproduces the ledger's published
metrics exactly (entailed precision 0.9884, contradiction recall 0.8875).

## Why it matters

`VERDICTS_DIR` is a module-level constant used directly at `:397` with no override, so
anything that drives the runner to scoring completion writes into the live artifact
directory under whatever identity the run carries. The directory is gitignored and no
checksum of the genuine artifact is recorded anywhere. T2.119 mints a gate evidence record
by re-scoring a file from this directory. *"Minted only by a cleared run, never by hand"*
is currently one text-editor session away from being violated undetectably.

## Done when

- The writer takes an output-directory override; every test path uses a temporary one.
- A regression test fails if a test run can write into the real directory. Find the actual
  leak source first — do not guess. Reproduce it, then fix it.
- The 79 residue files are removed **with their identification recorded** (filename,
  identity, gold sha, pair count, measured entailed precision and contradiction recall) so
  the deletion is auditable rather than a silent cleanup.
- The genuine artifact's sha256 is recorded **outside** the artifact: in its eval report
  (`docs/eval/2026-08-12-judge-qualification-fd39e7b2.md`) and in `gate-ledger.md`.

## Constraints

- Do not delete anything before its identification is written down and committed.
- Do not touch the gold, the cache, or any bar.
- Make no live model call; this task runs entirely offline.
