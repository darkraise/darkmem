### F3. Lattice sizing, both classes, with the arithmetic

Achievable recall scores on a class of N rows are k/N, so a bar b is exactly
representable iff b·N is an integer:

- **Entailed recall bar 0.90**: exact iff N ≡ 0 (mod 10). At N = 100 the minimum pass
  is exactly 90/100 = 0.9000. (The retired class's 173 gave 156/173 = 0.9017 — the
  defect ground 2 names.)
- **Contradiction recall bar 0.95**: exact iff N ≡ 0 (mod 20). At N = 40 the minimum
  pass is exactly 38/40 = 0.9500.
- **The two precision bars (entailed 0.95, contradiction 0.70) cannot be made
  lattice-exact by any census sizing, and the plan says so rather than pretending
  otherwise**: a precision denominator is the judge's accept count for that verdict,
  which is a property of the run, not the census. The obstruction is structural. What
  census sizing buys precision is only resolution, not exactness; the bars gate as
  stated and their effective granularity is disclosed per run by the existing report
  machinery.
- **The T2.115 two-population obstruction does not bite here, and this is why.** That
  round had to satisfy `N_contacted ≡ 0` and `N_contacted + N_ruleB ≡ 0 (mod 20)`
  simultaneously with a fixed contacted census of 55, which has no solution. A fresh
  gold has an **empty** contacted population: with ids continued at `eg-0418+`, every
  live pair satisfies `id >= RULE_B_FIRST_ID`, so `rule_b_population` returns the whole
  census and the pooled and Rule B populations are **the same set**. One congruence per
  class, both satisfiable, no simultaneous system. The load-bearing premise is the id
  continuation in F1 — a restarted id sequence would instead empty Rule B and break the
  report's second population; step 4 pins this with a test.
- **The independent-propositions reading coincides with the rows reading by
  construction, or the round is not done.** `census_independence` now counts connected
  components (T2.123, verified landed in `judge_qualification.py`), so a component of k
  duplicate rows collapses k−1. This round's accepted-duplicate set is **empty**: step
  6 loops retire-and-replace until `find_duplicate_propositions` reports zero findings,
  so independent = rows for both classes and the lattice statement above holds on both
  readings. A tolerated duplicate would silently move the independent reading's
  effective bar off the lattice — which is one more reason, needing no score, to
  tolerate none.

### F4. Parties and the firewall — mechanism, not label

- **The controller** (the session executing this plan) is presumed contaminated — a
  controller cannot do its job without reading the ledger — and therefore **authors no
  pair and adjudicates no pair**. It dispatches, runs mechanical checks, and commits.
- **Authors**: one fresh subagent per batch, whose dispatch contains its brief and
  nothing else. Allowed reads: the brief (slot assignments: premise or premise-class,
  slice, target verdict/window state), `LABELLING.md` **above the strip truncation
  point**, and `app/taxonomy.py`. Forbidden reads, enumerated in the brief and
  attested in the batch artifact: `gate-ledger.md`, `docs/eval/`, `docs/planning/`
  (including the M1 task file and **this plan**), qualification reports,
  `resample_runs/`, `entailment/cache/`, `entailment/verdicts/`,
  `entailment/retired/`, and LABELLING.md below the truncation point.
- **Adjudicators**: two separately dispatched fresh subagents, each receiving only the
  `strip_for_blind` export (id, premise, hypothesis — generated by committed code, so
  what they can see is a property of the tree, not of the prompt), plus the same
  bounded rulebook read. No shared context, batch isolation, merge per the ratified
  protocol.
- **Quarantine before any authoring dispatch**: `entailment/cache/` and
  `entailment/verdicts/` are moved outside the repository (both gitignored), per the
  ratified quarantine clause.
- **What is mechanical here, honestly stated.** Three things are machine-checkable:
  the git ordering (frame and briefs committed before any pair; pairs before the blind
  export; both passes before the merge — anyone can re-derive who could have seen what),
  the stripped export's content (committed code), and the digest checks (hash
  comparisons run by the controller, invisible to authors). The residual is the same
  one every prior round recorded: nothing physically stops an agent from reading a file
  it was forbidden, so attestations are recorded and the ordering proof is what makes a
  violation detectable rather than impossible.
- **The Claude-family caveat, carried rather than reintroduced.** T2.54 established
  that a Claude-family second pass adds near-zero bits and diverges identically. The
  two Layer-2 passes are therefore retained for what they demonstrably are — a
  divergence detector that has caught real escalations — and are **not** counted as
  the label-quality certification. Certification is Layer 3's: the owner's escalation
  rulings plus the seeded n = 93 blind resample sat by a **non-Claude model under owner
  direction** (precedent: deepseek-v4-pro via `resample_llm.py`, recorded `--from-raw`).
  No step below describes pass-A/pass-B agreement as independence.

- **O1 — contradicted census size.** The mechanical rule (nearest lattice multiple of

  the same apportionment rule; or total grows). Default: **40**, because it is the
  number the stated rule produces and no score-free argument in hand outweighs the
  rule. The owner's call either way lands in step 0, before anything is committed.
- **O2 — the overreach-contradicted 0 cell.** Mechanically derived, disclosed in F2.
  Default: accept it. The owner may move one slot (e.g. one unsupported-overreach →
  contradicted-overreach, with a compensating slot elsewhere to hold the class
  lattices) in step 0.
- **O3 — the resample sitting model.** The protocol requires non-Claude and
  owner-directed. Precedent is deepseek-v4-pro, and the standing objection recorded in
