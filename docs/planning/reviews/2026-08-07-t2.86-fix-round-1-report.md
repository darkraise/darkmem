## F3 (Minor) — half-vacuous negative assertion

**Finding:** `fact-detail.test.tsx`'s "a stale code citation renders as
stale, not as disputed" test's `queryByText("disputed")` half held
trivially, because that fixture's `verification_status` was not `disputed` —
the string could not have rendered regardless of the stale treatment.

**Fix:** added a second test, "a stale source group inside a disputed fact
still reads as stale, not disputed", using a fixture that both carries an
open dispute (`verification_status: "disputed"`, a populated `dispute` object)
*and* a stale source group. Because the page now legitimately contains the
word "disputed" elsewhere (the verification badge, the claim string), a
global `queryByText` would be meaningless; the assertion is scoped with
`within()` to the stale group's own container element (found via
`.closest<HTMLDivElement>("div.rounded-md")` from the group's `origin_key`
text), asserting `getByText("stale")` present and `queryByText(/disputed/i)`
absent *within that element specifically*. The test first confirms the
fixture is genuinely disputed (`findByText(DISPUTED_CLAIM)`) so the scoped
absence check is non-vacuous by construction.

Left the original test's fixture and both its assertions in place —
`F3` asked to make the negative half bite or delete it and justify keeping
only the positive; the new test supersedes rather than replaces the old
one's coverage, so both stayed (the original's positive half is unique
coverage: a stale-but-not-disputed fact, the far more common real case).

**Drilled:** added `{group.stale && <span>disputed</span>}` next to the
`StaleBadge` render in `fact-sources.tsx`, re-ran `npm test -- fact-detail`.
Both the original test and the new one went red:

```
FAIL  ... > a stale code citation renders as stale, not as disputed
FAIL  ... > a stale source group inside a disputed fact still reads as stale, not disputed
Tests  2 failed | 18 passed (20)
```

Reverted the drill line, re-ran — both green, 20/20. Confirms the negative
half now catches exactly the regression class it claims to.
