## Findings

### Finding 1 — Important, blocks the cut: the origin canonicaliser still splits one source into two origins, and the release says it cannot

`CHANGELOG.md` (`## v0.5`, Fixed): *"Repaired merge-only"*. `CLAUDE.md` (Domain
model): *"Every step of that canonicalisation is merge-only by construction: no input
may split one source into two ids"*. `backend/app/services/auto_research.py:334`
repeats it. The claim was falsified once, repaired for six shapes, and this review
falsifies the repaired version. Adversarial driver: 26 same-source spelling pairs,
**11 splits**. The two that meet T3.08's own "this repo's toolchain produces it"
standard:

1. **IDNA2008 vs IDNA2003 deviation characters**
   (`auto_research.py:284`, `host.encode("idna")` — Python's codec is IDNA2003).
   Verified against the installed client: `str(httpx.URL("https://straße.example/a"))`
   → `https://xn--strae-oqa.example/a` (httpx uses the `idna` package, IDNA2008),
   while the unicode spelling canonicalises through the 2003 codec to
   `strasse.example/a`. One page, two origins: a gatherer storing
   `str(response.url)` and one storing the scraped href split permanently. Same for
   final sigma (`βόλος.example` → `xn--nxasmq6b` vs httpx's `xn--wxaikc6b`). The
   committed test pins only `bücher` (`tests/test_research_origins.py:246`), where
   2003 and 2008 agree — the repair was pinned on the easy case. Under the ladder's
   own terms, two same-kind origins ≥ 7 days apart promote at N = 2, so a 7-day-apart
   refetch of one deviation-character page is a promotion off a single source — the
   exact failure T3.08's review graded Critical pre-arming.
2. **Trailing-dot FQDN with an explicit default port** (`auto_research.py:273-277`,
   an ordering bug): `.rstrip(".")` runs *before* the `:443`/`:80` strip, so
   `https://example.test.:443/a` → `example.test./a` while `https://example.test/a` →
   `example.test/a`. (`https://example.test./a` alone merges correctly — the dot
   survives only when a default port shields it.) Fix: strip the port before the
   trailing dot, or rstrip again after.

Nine further splits, each exotic alone but jointly refuting "by construction"
(driver preserved at the scratchpad; reproduce with
`origin_attack.py`): scheme-without-slashes hrefs (`https:example.test/a`, the
malformed form browsers normalise — `auto_research.py:299`'s prefix heuristic treats
`https:` as part of the host); root-level dot-segments gluing path onto host
(`/​../a` → segments `["", "..", "a"]` pops the leading empty segment, yielding
`example.testa` — both a split against `/a` and a cross-host identity collision —
`auto_research.py:259-267`); the `urlsplit`-ValueError fallback at
`auto_research.py:353-359` using the **pre-NFC** `value`, so NFC/NFD spellings of a
confusable-containing id split (the NFC normalise lives inside `_canonical_locator`,
after the point that raises); IPv6 zero-compression variants; a port with a leading
zero (`:0443`); embedded tab/newline in a scraped href (the URL standard strips them;
`_WHITESPACE_RE` converts them to `-`).

**Why this blocks a cut it does not endanger operationally.** The loop is genuinely
inert (Section "Arming boundary" below) and nothing in the tag can manufacture
evidence today. What is wrong is the release text: the headline of v0.5 *is* origin
discipline, and its central property is asserted as absolute, was already falsified
once, and is falsified again — a claim stated more strongly than the evidence
supports, on the exact surface this version exists to be honest about. Discharge
routes, either sufficient:

- **Preferred:** land the repairs (four localized edits: port-before-dot ordering;
  NFC-normalise before the try in `research_origin_id`; route host encoding through
  the `idna` package httpx already vendors, falling back to the codec; treat a
  leading `..` as unresolvable at root) with the failing shapes pinned red-first,
  as T3.08 did.
- **Minimal:** reword `CHANGELOG.md` and `CLAUDE.md` to the verified bound — the
  canonicalisation is merge-only against the mechanical variation catalogued and
  pinned; adversarial spellings outside that catalogue (IDNA deviation characters
  among them) still split, all behind the disarmed switch — and file the repairs as
  a pre-arming blocker task, since arming with known splitting inputs re-opens the
  manufactured-corroboration hazard the version claims to have closed.
