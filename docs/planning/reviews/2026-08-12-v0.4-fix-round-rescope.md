## The judgement call — leaving the L3 fragments unregistered **holds**

Verified empirically, not from the comment: registering the five L3 fragments in
`CLAIM_VOCABULARY` and running both scans flags
`app/services/claim_entailment.py` (`["cited fact", "cited facts"]`) on the backend and
`article-detail-live.tsx` (`["grounded by", "cited fact", "claim-support coverage"]`) plus
`articles-tab.tsx` (`["claim-support coverage", "claim-support coverage not measured"]`)
on the frontend — precisely the surfaces doc 13 §5.2 orders to spell the label
(*"the surface labels it 'claim-support coverage,' not a vague score"*,
`13-frontend-architecture-and-ia.md:228`). The premise is real: registration outlaws
mandated wording, and under the scans' ≥ 2-distinct-fragments predicate there is **no
registration subset** that would catch a composed L3 sentence without false-flagging that
legitimate copy (a composer tripping the threshold needs two registered fragments, and any
two L3 fragments already co-occur legitimately in the files above). The certainty-word
guard does run over the whole assembled L3 sentence (`build_article_claim` → `_render`),
and the L2 fragments keep guarding the general second-producer discipline.

**Accepted residual, named:** a second module composing an L3-shaped sentence
("grounded by N cited facts, …") is invisible to both scans — the same residual class the
backend scan already documents for sub-threshold paraphrases ("caught by review, not by
this test"). One sentence in the definition's comment overstates the mitigation — a
second composer would *not* "have to reimplement this function", it could just spell the
string — but the decision does not rest on that sentence and stands on the measured
grounds above.

## Deferred observations — recorded, not looped on

1. **A gate-suppressed article's staleness is invisible on the composed doors** (measured:
   `corroborated` row, no gate record → `badge: null`, and `stale` rides only the badge
   there). Inherited interaction of two ratified designs — doc 12 places `stale` inside
   the badge; T2.95 forbids a withheld status carrying a badge — not this fix's invention,
   and unreachable today (a promoted article implies the record existed; only a revoked
   record opens the window). The list/detail doors serve row-level `stale` regardless.
   Worth one sentence wherever the record-revocation procedure is eventually written.
2. **`test_a_composed_read_serves_an_article_rather_than_raising` ends with
   `assert str(article_id)`** — a tautology (any UUID string is truthy). Harmless; the
   real assertions precede it; tighten to `badge is badges[f"article:{article_id}"]`-style
   at leisure.
3. **The old source-inspection wiring test still exists**
   (`test_the_channel_is_wired_into_the_composition`, `test_articles_channel.py:391`) —
   now redundant beside the executed tests, and its shape is the one the branch review
   indicted. Keep or fold; it can no longer be the *only* guard, which was the defect.
4. **The in-tree executed guard stops at `derive_badges` + unit-level `compose`;** the
   full door-level join lives in this re-review's driver, not the suite. Acceptable: the
   mutation evidence shows the seam is covered from four directions (new executed tests,
   the keyspace unit pin, and the fact-side door tests), and the commit's "drives
   `compose`" phrasing is only loosely accurate — the new test drives the badge mint, and
   `compose` is executed with an article badge by `test_the_badge_map_is_keyed_in_the_
   composition_keyspace`.
5. **`list_open_articles` reads items before totals in separate statements**, so a
   concurrent commit between them can skew one page boundary — pre-existing pattern shared
   with the facts arm, cosmetic at queue scale.
6. **I5's page-bound `withheld` count** (strip counts the fetched page, default 50)
   remains as the branch review already recorded it — minor, unchanged, not part of I5's
   verdict.
7. **`badges_for_articles`' docstring misattributes its quote.** "its provenance is only
   its cited facts" is doc **13**'s sentence (`13-frontend-architecture-and-ia.md:228`,
   the doc-16 firewall paragraph), not doc 09's as the docstring claims — doc 09 states
   the substance but not those words. One doc-number fix whenever the file is next
