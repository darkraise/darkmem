darkmem capture

Only http://localhost:8000 works today. The manifest grants this extension network access to that one origin, so a LAN address saves fine and then fails on every capture — the browser blocks the request before darkmem sees it. Reaching a LAN instance means widening host_permissions in the manifest and reloading the extension, which is a deliberate re-grant rather than a setting: a capture extension that could post anywhere is a different trust posture from one that cannot.

This install's origin_key is …. It is minted once and never changes: darkmem counts distinct origins to decide whether a claim is corroborated, so a key that changed per session would let this browser agree with itself.
